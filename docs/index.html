Scrub

Removes EXIF, GPS, camera and author metadata from photos and video.

Everything happens inside this browser tab. Your files are never uploaded anywhere — there is no server to upload them to.

Drop photos or videos here or click to choose — JPEG, PNG, WebP, MP4 and MOV

    What this can and cannot do

    Nothing here is re-encoded, so image and video quality is never touched. JPEG, PNG and WebP files are rebuilt from their image data alone. MP4 and MOV files have their metadata boxes overwritten in place with padding, because the video's sample table points at absolute byte positions — shifting them would break playback. The file size therefore stays the same for video, while the metadata itself is genuinely gone.

    Metadata is not the only way a file identifies its source. Watermarks, a platform's own re-encoding fingerprints and the visible content all survive stripping. What this removes is the embedded tags — the part that quietly carries your location, device and name.

    Need HEIC, MKV, AVI, or want to pull a video straight from a Facebook or Instagram link? That needs ffmpeg and yt-dlp, which cannot run in a browser tab. The local version on GitHub does all of it.
